# Agenda de Contatos (MVC)

Aplicação para gerenciamento de contatos desenvolvida com arquitetura MVC.

![Demonstração da Agenda](demonstracao-agenda.png)

## Funcionalidades

- Adição e remoção de contatos.
- Listagem dinâmica.
- Persistência com `localStorage`.

## Tecnologias

- JavaScript (ES6 Modules)
- MVC
- `localStorage`
